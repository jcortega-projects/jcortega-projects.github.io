Rehabilitation AI Partner

A human-centered RL research project for improving physical therapy adherence with personalized interventions.

Project Summary

Architecting an RL-driven "Rehab Partner" integrating Ecological Momentary Assessment (EMA) for state monitoring and Just-In-Time Adaptive Interventions (JITAI) for personalized behavioral feedback.

Primary objective: optimize exercise consistency and long-term physical therapy adherence.

Core Components

  • Behavior state estimation from EMA signals
  • Policy learning for intervention timing and type
  • Feedback personalization loop with adherence metrics
